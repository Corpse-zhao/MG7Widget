# 控车接口逆向指南（P5）

目标：找出 MG Live 的控车接口 —— **解锁 / 锁车 / 远程空调**。

---

## 现状（已确认）

- MG Linker 现版本**只有只读车况接口**（`getVehicleStatus`），控车代码已移除，
  git 历史只有 1 个 commit，**挖不出旧实现** → 必须抓包
- 车况接口是**独立的**，控车走另一套接口
- 好消息：车况那条链路（token 认证方式）已完全打通，
  控车**大概率共用同一个 token**，只是路径和参数不同

---

## 抓包步骤（请严格按顺序）

### 0. 前置

- **MG Live 已登录**，且车厢信号良好（控车指令需要车联网在线，车要能收到）
- 车停在**安全位置**（要真的执行解锁，别在路边试）
- Stream 已开启抓包

### 1. 清空干扰，先做一次"基准"

先**只下拉刷新一次首页**（触发车况请求），记住这个时间点。
这样后面能从一堆请求里区分「只读的」和「控车的」。

### 2. 依次操作三次，每次间隔 10 秒

**只点一次，等它显示执行成功再点下一个：**

| 顺序 | 操作 | 记录时间 |
|---|---|---|
| 1 | 点「**解锁**」 | ____:____ |
| 2 | 点「**锁车**」 | ____:____ |
| 3 | 点「**开启空调**」（默认参数直接确定） | ____:____ |

> 如果 App 里有「车窗」「后备箱」「寻车」等，也顺手点一下，多抓几个更省事。

### 3. 停止抓包，筛选

在 Stream 记录里找 **POST 请求**，优先看这几类：

- **host 是 `mp.ebanma.com`** 且路径含 `/vp/` —— 最可能
- 路径含 `control` / `command` / `lock` / `climate` / `ac` / `remote` / `vehicle`
- 响应体里有「指令下发成功」「操作成功」「下发中」之类
- **时间点和你上面记的对得上**

### 4. ⚠️ 重点：三条一起发我

**不要只发一条**。要对比才能找出「哪个字段是变化的」（那就是指令本体）。
每个操作给我这五项：

```
① 完整 URL（含 query）
② 请求方法 + Content-Type
③ 全部请求头（尤其 sign / token / userid / timestamp / watch-man）
④ 请求体全文（JSON 或表单）
⑤ 响应体全文
```

---

## 我这边收到后怎么做

1. **三条对比**，找出变化的字段 → 那就是指令参数（通常是 `command` / `cmd` / `type` 之类）
2. **判断签名**：
   - `sign` 每次都变 → 可能是 `MD5(排序参数 + 密钥)`，需从 App 二进制抠密钥
   - `sign` 固定或没有 → **直接重放，当天就能上**
3. 写进 `SAICService.sendCommand`
4. **先测只读的「指令状态查询」**，确认通了再真控车

---

## 风险提示

- 控车接口风控通常更严，可能校验设备指纹
- 若 `sign` 用 App 内密钥计算，两条路：
  - 越狱环境 dump MG Live 可执行文件，用 IDA/Ghidra 找签名函数
  - **推荐：写 Theos 插件 hook 它的签名函数**（省事，且密钥永不过期）

---

## 备选方案（如果接口逆向受阻）

**直接 hook MG Live 自己**：
- Theos 插件 hook MG Live 的控车方法
- 我们的 App 通过 XPC / Darwin 通知 / URL Scheme 触发它执行
- 优点：不用管签名（App 自己算）
- 缺点：需要 MG Live 在后台运行

这套技术和 MGHelper 同源，实现成本可控。

---

## 如果完全拿不到

退一步的**降级方案**（不依赖逆向）：
- 小组件/App 里放一个「打开 MG Live」的按钮，用 URL Scheme 直接跳转
- 至少省掉「找 App → 进控车页」几步，属于聊胜于无
