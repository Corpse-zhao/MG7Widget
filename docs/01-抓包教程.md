# MG Live 抓包教程（MG7 · iOS / 安卓）

目标：拿到 4 个关键值 —— `ACCESS_TOKEN`、`VIN`、`user_id`、`user_name`（后两个用于控车）。

---

## 方案选择

| 方案 | 设备要求 | 推荐度 | 说明 |
|---|---|---|---|
| A. Stream (iOS) | iPhone 单独一个 App，无需电脑 | ★★★ | 最适合你，直接抓 MG Live |
| B. HttpCanary (安卓) | 任意安卓机 | ★★☆ | 社区 MG Linker 项目就是用这个，步骤最成熟 |
| C. Charles / mitmproxy | 需要电脑 | ★☆☆ | 最灵活但要配代理和证书 |

**推荐方案 A（Stream）** —— 装在 iPhone 上，无需电脑，微信登录也拦得住。

---

## 方案 A：Stream (iOS) 详细步骤

### 1. 安装

App Store 搜 `Stream`（图标是蓝色抓包工具），免费。装好后打开。

### 2. 安装证书（必须，否则 HTTPS 抓不到）

1. Stream 首页 → 「HTTPS 抓包」→ 「安装证书」
2. 会跳转到 Safari 下载一个 `.pem` 描述文件
3. 打开 **设置 → 通用 → VPN与设备管理** → 找到 Stream 的描述文件 → 安装
4. 打开 **设置 → 通用 → 关于本机 → 证书信任设置** → 把 Stream 的开关**打开**
5. 回到 Stream → 「HTTPS 抓包」→ 打开总开关

### 3. 开始抓包

1. Stream 首页点 **「开始抓包」**
2. 切到 **MG Live** App，做一次**刷新操作**（下拉首页，或点进「爱车」页面触发车况刷新）
3. 回到 Stream，点 **「停止抓包」**

### 4. 找 ACCESS_TOKEN（关键）

在 Stream 的抓包记录里，**按域名筛选**，找 `mp.ebanma.com` 开头的请求。

打开任意一个该域名的请求 → **请求头 (Request Headers)** → 找 key 类似 `Access-Token` / `access_token` / `Authorization` 的字段。

**特征**：这个值**以 `-prod_SAIC` 结尾**。找到它。

> 示例形态：`xxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx-prod_SAIC`
> ⚠️ 这是敏感凭证，等于你的账号登录态，不要外发。

### 5. 找 VIN

VIN 有几种拿法，任选：

- **方法一（最稳）**：抓包记录里搜 `LSJ`，通常出现在车况接口返回的 JSON 里，字段名一般是 `vin`
- **方法二**：MG Live App → 「我的」→ 车辆管理 → 车辆详情，看车架号
- **方法三**：行驶证 / 前挡风玻璃左下角

**特征**：`LSJ` 开头，共 **17 位**。

### 6. 找 user_id / user_name（控车才需要）

在抓包记录里找这个接口：

```
https://capi-pv.saicmotor.com/app-mp/uais/1.1/fetchCcmUserInfoV2
```

打开它的**响应 (Response)**，JSON 里的：
- `uid` → 这就是 `user_id`
- `username` → 这就是 `user_name`

> 也可以直接进 MG Live 的「我的」页面，触发这个接口。

## 常见坑

- **抓不到 HTTPS**：证书信任开关没开（第 4 步），或者忘了重启 MG Live
- **MG Live 检测到代理不给数据**：切换成「直连模式」再抓，或用安卓方案 B
- **token 抓到了但调接口 401**：token 有时效，抓完立刻用
- **Stream 只能看到 CONNECT**：说明证书没装好，重做第 2 步
