# MGLiveWidget 技术架构

目标：在 iPhone 14 Pro Max / iOS 16.6 / roothide 隐根 上，实现 MG7 的**独立控制 App + 桌面 WidgetKit 小组件**。

---

## 一、核心约束（决定了整个架构）

| 约束 | 影响 |
|---|---|
| WidgetKit Extension 必须 Xcode 编译 | Theos 做不了，必须 macOS 运行器（GitHub Actions） |
| Widget Extension 与宿主 App 是**独立进程、独立沙盒** | 数据必须共享 |
| roothide 下 **App Group 失效** | 共享方案不能用 App Group，改用固定路径文件 |
| 宿主 App 读不到 MG Live 沙盒（沙盒隔离） | 越狱辅助工具负责读取，写入共享路径 |
| 小组件进程**不能主动联网**（iOS 限制） | 联网必须由宿主 App 做，结果写共享文件 |

**结论**：必须三件套协作。

---

## 二、三件套架构

```
┌─────────────────────────────────────────────────────────────┐
│  ① MGWidgetHost.app  （Xcode 编译，含 WidgetKit Extension）   │
│     · 主界面：车况总览 / 控车按钮 / 刷新                       │
│     · 负责联网调 SAIC 接口                                    │
│     · 把车况快照写入共享文件                                  │
│     · 通过 WidgetCenter.reloadAllTimelines() 触发小组件刷新   │
└───────────────┬─────────────────────────────────────────────┘
                │ 读写
                ▼
┌─────────────────────────────────────────────────────────────┐
│  ③ 共享数据层（固定路径，绕开 App Group）                     │
│     /var/mobile/Library/MGLiveWidget/                        │
│        ├── token.plist      ← ACCESS_TOKEN / user_id / VIN   │
│        └── snapshot.json    ← 最近一次车况快照（小组件读它）   │
└───────────────▲─────────────────────────────────────────────┘
                │ 写入
┌───────────────┴─────────────────────────────────────────────┐
│  ② MGHelper（Theos 编译，越狱辅助工具 / 插件）                │
│     · 越狱权限读 MG Live 沙盒，自动捞 ACCESS_TOKEN            │
│     · 可选：后台轮询，保持 token 新鲜                         │
│     · 免去手动抓包填 token（抓包只在开发期用一次）             │
└─────────────────────────────────────────────────────────────┘
```

### 各组件职责

**① 宿主 App（MGWidgetHost）**
- Xcode 工程，含 `MGWidgetExt` target
- 网络层：调 SAIC 接口，解析车况
- UI：车况卡片 + 控车按钮
- 写 `snapshot.json` 到共享路径
- 调用 `WidgetCenter` 通知刷新

**② 越狱辅助（MGHelper）**
- Theos 工程，`THEOS_PACKAGE_SCHEME=roothide`
- 用 roothide 的 `jbroot()` 宏解析路径
- 读 MG Live 容器路径，从 keychain / plist 取 token
- 需要 entitlements：
  ```
  platform-application
  com.apple.private.security.no-sandbox
  com.apple.private.security.storage.AppBundles
  com.apple.private.security.storage.AppDataContainers
  ```

**③ 共享数据层**
- roothide 下 App Group 不可靠，统一用 `/var/mobile/Library/MGLiveWidget/`
- 两个文件：
  - `token.plist`：登录凭证（权限 600）
  - `snapshot.json`：车况快照，小组件直接读

## 三、数据流时序

### 场景 1：用户在 App 里点刷新

```
用户点刷新
  → 宿主 App 读 token.plist 拿 ACCESS_TOKEN
  → 调 SAIC 接口（https://mp.ebanma.com / capi-pv.saicmotor.com）
  → 解析 JSON / ASN.1 → 得到车况
  → 写 snapshot.json
  → WidgetCenter.reloadAllTimelines()
  → 系统唤醒 Widget Extension
  → Extension 读 snapshot.json → 渲染
```

### 场景 2：小组件自动定时刷新

```
系统按 timeline policy 唤醒 Extension（最早 15 分钟一次）
  → Extension 读 snapshot.json（不能联网！）
  → 渲染上一次的数据
  → 如需新数据，Extension 只能标记"需刷新"，
     实际联网要靠宿主 App 后台或用户手动打开
```

> ⚠️ **重要限制**：iOS 不允许 Widget Extension 主动联网，也不保证刷新频率。
> 想近实时，方案是宿主 App 用 BackgroundTask 定时拉取。
> 越狱环境下可以更进一步 —— 用 Theos 写个 LaunchDaemon 常驻拉取（可选，二期再做）。

## 四、编译方案（关键，你踩过坑）

| 组件 | 编译环境 | 说明 |
|---|---|---|
| ① 宿主 App + Widget Ext | **macOS 运行器**（GitHub Actions） | Xcode 必须；arm64e 必须 Apple 原生 clang |
| ② MGHelper | 可 Windows 本地 Theos，但**建议同样 macOS** | 保持一致，避免工具链差异 |
| deb 打包 | `gmake package THEOS_PACKAGE_SCHEME=roothide` | |

**CI 注意点**（沿用 SMSVideoBG 教训）：
- `runs-on: macos-latest`
- `brew install make xz ldid`
- 用 `gmake` 不是 `make`
- Apple ld 不搜 SDK PrivateFrameworks，链接私有框架要显式 `-F`

## 六、安全注意

- `token.plist` 权限设 `600`，仅 mobile 可读
- 控车接口调用前必须二次确认 UI
- token 等于完整账号态，日志里禁止打印
- App 内不做任何静默控车
